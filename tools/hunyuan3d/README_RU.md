# Hunyuan3D для Заргата (экспериментальная ветка)

Здесь находится отдельный эксперимент по созданию новой модели Заргата. Основная ветка и существующая модель не изменяются.

## Запуск

[Открыть ноутбук Заргата в Google Colab](https://colab.research.google.com/github/itolki58-pixel/omoba-bevy/blob/hunyuan3d-zargat/tools/hunyuan3d/notebooks/Hunyuan3D_Zaragat_Colab.ipynb)

1. В Colab выбери «Среда выполнения» → «Сменить среду выполнения» → GPU (если доступно бесплатно).
2. Запускай ячейки по порядку.
3. Для входа нужен один чистый фронтальный вид персонажа целиком, без подписей и других ракурсов. Не используй весь коллаж как один вход.
4. Первая версия ноутбука создаёт геометрию без текстуры. Сначала проверяем форму, затем отдельно добавляем текстуру, скелет и анимации.

## Ограничения

- GT 650 не подходит для локальной генерации.
- Бесплатная облачная GPU не гарантирована. GitHub Actions не предоставляет автоматически GPU для этой задачи.
- Hunyuan3D создаёт меш и, отдельным этапом, текстуру; он не делает игровой скелет и анимации.
- Модельный зоопарк Tencent указывает около 6 ГБ VRAM для формы и около 16 ГБ для формы с текстурой. Это ориентиры из официального README, а не гарантия запуска на любой среде.
- До распространения игры нужно проверить лицензию конкретной версии/весов и ограничения для предполагаемого использования.
