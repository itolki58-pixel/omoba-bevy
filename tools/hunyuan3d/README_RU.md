# Hunyuan3D для Заргата (экспериментальная ветка)

Эта папка содержит инструкции и ноутбук для отдельного этапа создания новой 3D-модели Заргата с помощью официального проекта Tencent Hunyuan3D-2.

## Важно

- Исходный код и веса Hunyuan3D **не копируются** в этот репозиторий: они большие, обновляются отдельно и распространяются по собственной лицензии.
- Используем официальный репозиторий: https://github.com/Tencent-Hunyuan/Hunyuan3D-2
- Видеокарта GT 650 не подходит для локального запуска этой модели. Генерацию планируем выполнять в бесплатной облачной GPU-среде, если там будет доступен совместимый ускоритель. Бесплатная GPU-сессия не гарантирована.
- Официальный README указывает ориентиры около 6 ГБ VRAM для генерации формы и около 16 ГБ для генерации формы вместе с текстурами. Фактический расход зависит от версии и настроек.
- Hunyuan3D создаёт геометрию и текстуру, но сам по себе не делает игровой скелет и анимации. Это будет отдельный этап после выбора модели.
- До распространения игры необходимо отдельно проверить лицензию именно выбранных весов/версии и все ограничения для предполагаемого использования.

## Быстрый старт

1. Открой ноутбук `notebooks/Hunyuan3D_Zaragat_Colab.ipynb` в Google Colab.
2. В меню Colab выбери **Среда выполнения → Сменить среду выполнения → T4 GPU** (если такой вариант доступен бесплатно).
3. Запусти ячейки по порядку. Первая проверит, выдан ли GPU.
4. Для первого теста загрузи чистый фронтальный вид Заргата на нейтральном фоне. Не используй лист с подписями, рамками и несколькими ракурсами в одной картинке: сначала проверим качество одного вида.
5. Сначала получим форму без текстуры. Текстурирование запускай только если хватает видеопамяти.
6. Скачанный GLB нужно будет передать в эту ветку OMOBA для проверки, оптимизации и риггинга.

## Почему не GitHub Actions

Обычный GitHub-hosted runner не означает наличие подходящей NVIDIA GPU. Поэтому Actions не запускает тяжёлую генерацию автоматически. GitHub хранит интеграционные инструкции и результат; сама генерация выполняется в отдельной GPU-сессии.
